Scope 
The present sample document describes metadata carried alongside a multiplex of 
example media streams, so that a receiver can present choices to a user 
and apply automatic configuration for the selected programme. Core signalling for 
automatic configuration is mostly defined in Sample Spec 1000-1 [1] as 
stream maps. 
The present sample document adds complementary fields that help receivers locate 
services and show short labels to the user. Presentation style is not 
mandated here; implementers may choose suitable layouts. 
An interactive guide feature is expected in some deployments. 
Defining that guide UI is outside the scope of the present sample document, but the fields 
here may feed such a guide. 
Operational rules for applying this sample appear in Sample Spec 2000 [i.1].
